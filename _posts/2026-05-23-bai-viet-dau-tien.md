## Chào mừng đến với blog của tôi!

Đây là bài viết đầu tiên trên blog cá nhân được xây dựng bằng **Jekyll** và theme **Chirpy**, host trên **GitHub Pages** — hoàn toàn miễn phí.

## Tại sao chọn Jekyll + Chirpy?

- **Miễn phí**: GitHub Pages host static site không tốn phí
- **Nhanh**: Không có database, không có server-side rendering
- **Markdown**: Viết bài bằng Markdown, đơn giản và tập trung vào nội dung
- **SEO tốt**: Chirpy tích hợp sẵn SEO, sitemap, Open Graph
- **Dark/Light mode**: Tự động theo hệ thống hoặc chuyển thủ công

## Cấu trúc bài viết

Mỗi bài viết là một file `.md` trong thư mục `_posts/` với định dạng tên:

```
YYYY-MM-DD-ten-bai-viet.md
```

Front matter mẫu:

```yaml
---
title: "Tiêu đề bài viết"
date: 2026-05-23 10:00:00 +0700
categories: [Danh mục chính, Danh mục phụ]
tags: [tag1, tag2, tag3]
image:
  path: /assets/img/posts/thumbnail.jpg
  alt: Mô tả ảnh thumbnail
---
```

## Những chủ đề sắp tới

- Linux command-line tips & tricks
- Docker và containerization
- CI/CD với GitHub Actions
- Kubernetes cơ bản đến nâng cao
- Shell scripting thực tế
